09 / A FEW GOOD QUESTIONS

Before you begin.

Can I use MarkDev with files I already have?

Yes. Open a Markdown file directly, or open a folder as a vault. Saved Vaults remembers a folder’s location. It does not import, duplicate, or back up its contents.

Do I need AI to use the editor?

No. Writing, reading, and connecting notes do not require Apple Intelligence or MANVI. Assistance is optional. Apple Intelligence needs a supported, enabled, and ready system model; MANVI is installed and configured separately.

Does my writing stay on my Mac?

Notes are local files, and the Apple Intelligence writing path uses the on-device model. MANVI has its own provider settings and can use remote processing after confirmation. Files stored in a folder managed by a sync service follow that service’s behavior.

The integrated terminal can run networked tools with your account’s permissions. See the security policy for the full boundaries.

Will every Markdown extension render?

MarkDev supports CommonMark with selected extensions, a native HTML subset, and supported LaTeX and Mermaid forms. It does not provide a browser or JSX runtime, and it does not fetch remote images while reading a note. Check the syntax guide for compatibility limits.

Can I export or print a note?

Use File → Export as HTML… or Print… (⌘ P). HTML export uses a separate renderer. Inspect the output before sharing if you need the exact appearance of native math, diagrams, or other rich content.

Which Macs can run MarkDev?

The app requires macOS 26 or later. CPU support depends on the artifact: the published v0.0.3 archive is Apple silicon only, while current source has universal Release build settings. Read the download notes below before choosing a build.

Why might Finder previews behave differently?

Finder uses a separate Quick Look extension and chooses a provider through macOS. A registered extension is not proof Finder selected it, and ad-hoc signing does not provide notarization. The in-app peek uses MarkDev’s own preview surface. See troubleshooting for the checks.

How do I report a problem or contribute?

Start with a small, non-sensitive example and the exact app and macOS versions. Settings → Support offers bounded local diagnostic reports to review before sharing. Use GitHub issues for bugs and ideas, the contribution guide for development, and private vulnerability reporting for security findings.
