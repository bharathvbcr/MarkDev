# MarkDev v0.1.4

This release includes the editor improvements since the last published release, v0.0.2, and a hardened release pipeline.

## Editor improvements

- Heading-anchor and footnote navigation, with linked superscript footnote references.
- Table keyboard navigation and insertion of scaffolded rows.
- Editor zoom controls, selection word and character counts, and accessibility refinements.
- Display-scale-aware rendering for math and other rich content.
- A Settings window with appearance controls and a keyboard shortcut reference.

## Release reliability

- Tag releases run the Rust, release-contract, performance, and Swift test gates before building the release artifact.
- Staging verifies the app, framework, and Quick Look extension versions, build numbers, bundle identifiers, and Apple silicon architecture, then extracts and verifies the packaged app again.
- Each release includes a SHA-256 checksum and JSON manifest identifying the source commit, version, build, and architecture.
- Failed uploads can resume without deleting existing assets. Published releases and mismatched assets are protected from overwriting.

## Download and compatibility

Download `MarkDev-0.1.4-macos.zip` for **Apple silicon Macs running macOS 26 or later**. This is version **0.1.4, build 9**; an Intel binary is not included.

The app is **ad-hoc signed and not notarized**. Gatekeeper approval and Finder Quick Look extension registration are not provided by this build. Native editor behavior is covered by automated tests; physical Finder and accessibility interactions have not been revalidated for this release.

The checksum can be verified in the download directory with:

```sh
shasum -a 256 -c MarkDev-0.1.4-macos.zip.sha256
```
