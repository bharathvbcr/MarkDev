# MarkDev v0.0.4

Source milestone. No published GitHub release for this version was found on
2026-09-13; see the [release index](README.md) for available downloads.

This release introduces comprehensive GitHub README HTML compatibility, source-relative document link navigation, FFI bridge fixes, crash-safe local I/O and diagnostics, UI accessibility refinements, and enhanced Mermaid diagram rendering.

## GitHub README HTML and Rich Content Rendering

- Native rendering for HTML tables, aligned headings (`<h1>`–`<h6>`), and inline formatted runs (`<span>`, `<code>`, `<kbd>`, `<details>`, `<sub>`, `<sup>`, `<small>`, `<mark>`, `<u>`, `<s>`).
- Centered badge rows, taglines, hero images, and screenshot table cells render in place of raw markup; unknown HTML preserves source text and remote images remain blocked.
- Fenced math, LaTeX `\(...\)` and `\[...\]` delimiters, structured YAML/TOML frontmatter display, and task list strikethrough.
- Block and inline `<!-- … -->` comments collapse in reading and live-preview modes, expanding when the caret enters their block.
- Zoom viewer support for rendered HTML fragments and rich pictures.
- Mermaid diagram improvements: automatic HTML label sanitization before layout and horizontal packing for disconnected subgraphs.

## Document Links and Vault Navigation

- Source-relative Markdown links (`[label](path/to/note.md)` and `file:` paths) resolve alongside `[[wikilinks]]`, complete with heading-anchor scroll targeting.
- Document links automatically classify destinations to open notes in-pane, reveal folders in Finder, or launch external assets in default viewers.
- Vault backlinks and link graph index relative Markdown links.
- Note renames update both `[[wikilinks]]` and relative Markdown destination links across the vault.

## Architecture and FFI Bridge Hardening

- Correct block ordering and validation in the Swift-Rust FFI bridge, resolving parser rejections for nested lists, callouts, and blockquotes.
- C/Swift header contract verification ensuring all exported constants import cleanly without ClangImporter syntax rejections.
- Bounded token and memory ceilings across document parsing, syntax highlighting, and incremental edits.

## Crash-Safe Local I/O, Diagnostics, and Recovery

- Crash-safe document saving with transactional writes and local recovery journaling.
- Structured diagnostics pipeline (`DiagnosticsCenter` and rotating JSONL sink) capturing subsystem performance, errors, and cancellation telemetry without leaking private document contents.
- Interactive Close Review sheet managing unsaved document changes and active terminal processes before window dismissal.
- Non-blocking pipe streaming for harness processes, preventing hangs during cancellation or backstop timeouts.

## UI and Accessibility Refinements

- Window-owned Escape key handling to dismiss transient overlays (Quick Look peek and link graph) regardless of where focus sits.
- Modal accessibility traits for the Command Palette and destructive progress sheets, with automatic accessibility tree hiding for background surfaces.
- Preserved system keyboard focus ring on the file tree navigator for Full Keyboard Access.
- Responsive graph controls with `ViewThatFits` horizontal fallback for compact window widths.
- Accessible spoken names and hints across toolbar controls, including Save options.
