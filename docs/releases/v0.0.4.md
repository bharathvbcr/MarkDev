# MarkDev v0.0.4

This release introduces comprehensive GitHub README HTML compatibility, native HTML comment handling, and enhanced Mermaid diagram rendering.

## GitHub README HTML compatibility

- Native rendering for HTML tables, aligned headings (`<h1>`–`<h6>`), and inline formatted runs (`<span>`, `<code>`, `<kbd>`, `<details>`, `<sub>`, `<sup>`, `<small>`, `<mark>`, `<u>`, `<s>`).
- Centered badge rows, taglines, and hero images render in place of raw markup.
- Zoom viewer support for rendered HTML fragments.

## Native HTML comment handling

- Both block and inline `<!-- … -->` comments collapse in reading and live-preview modes.
- Comments remain fully editable and reveal when the caret moves into their containing block.

## Mermaid diagram improvements

- HTML labels within Mermaid diagrams are automatically sanitized before layout so native rendering matches GitHub formatting.
- Disconnected left-to-right subgraphs are packed horizontally.

## Download and compatibility

Download `MarkDev-0.0.4-macos.zip` for **Apple silicon Macs running macOS 26 or later**. This is version **0.0.4, build 10**; an Intel binary is not included.

The app is **ad-hoc signed and not notarized**, so Gatekeeper-trusted distribution to another Mac is not provided. Quick Look registration is macOS installation state and is not guaranteed by the archive; an exact `pluginkit` registration is necessary but still does not prove which provider Finder served for a particular preview. The source includes automated editor coverage, but physical Finder and accessibility interactions were not revalidated for this release.

The checksum can be verified in the download directory with:

```sh
shasum -a 256 -c MarkDev-0.0.4-macos.zip.sha256
```
