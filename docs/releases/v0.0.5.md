# MarkDev v0.0.5

Version 0.0.5, build 11, consolidates the Markdown core embedding work. The Rust
core exposes independently selectable features for hosts such as GitPulse while
the native application continues to build the complete editor and Quick Look
extension.

These are local release notes. No published GitHub release for this version
was found on 2026-09-13, and a recheck on 2026-09-29 still shows
[v0.0.3](https://github.com/bharathvbcr/MarkDev/releases/tag/v0.0.3) as the
latest published artifact; see the [release index](README.md). Installation
uses the atomic installer and checks the installed Quick Look registration.
Local ad-hoc signing does not provide Apple notarization or Gatekeeper-trusted
distribution.


## Subsequent source changes

The current source also includes saved-vault persistence and ongoing document,
asset, and diagnostics hardening. The documentation overhaul adds a user guide,
syntax and troubleshooting references, an explicit release index, corrected
architecture/graph contracts, and a standalone product website. These changes
are described by the source tree and are not a claim about a published binary.

## Local install of main

The installed build is `main` after tag `v0.0.5`, still bundled as version
0.0.5, build 11. It is not a new version and not a published download. The
bundle's source commit is the revision that contains these notes.

Since the tag, the editor and export path gained:

- Obsidian formatting in the editor, the vault, and HTML export: callouts
  (including folding), highlights, comments, note embeds, block references,
  nested heading links, custom task statuses, and the vault's attachment
  folder.
- **File → Export as HTML…** and **File → Preview in Browser** (`⌥⌘P`): a
  self-contained page with local SVG and raster images embedded, and math
  typeset as MathML.
- Links to files the page does not embed are written relative to where the
  page is saved.
- **File → Export Vault as Website…**: every note in the open vault becomes a
  linked page, with an index.
- A fix so a standalone `![[…]]` embed is not rejected by the picture gate.

Maintainer-only: pull-request app jobs run on the Xcode 27 image that carries
the pinned toolchain. The earlier Xcode 26.6 pin is superseded.
